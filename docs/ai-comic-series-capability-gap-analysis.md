# AI 漫剧长篇系统能力缺口分析

> 日期：2026-06-16
> 目标：梳理当前系统距离“可长期生产高质量 AI 漫剧”的剩余能力缺口，并给出开发优先级。

## 当前已具备

- 系列规划：集数、时长、阶段结构、角色弧线、长期线索、主线骨架、分集卡片。
- 保存项目：保存、加载、复制、归档、恢复、删除。
- 单集生成：按分集卡片生成完整故事、分镜、对白、GEARS 分段。
- 镜头交付：已支持按系列导出已生成分集的 Seedance 2.0 镜头提示词 Markdown / JSON，包含分集、镜头、人物、场景、运镜、连续性和禁用元素；导出后会登记 `seedance_production` 生产账本，可追踪镜头已导出、已提交、处理中、完成、失败或跳过；前端支持批量流转状态，并可导入视频 URL 回传 JSON；外部平台可通过带密钥的 callback 按 `job_id` 或 `episode_no + shot_id` 回写状态、质量分和评审备注；回片会形成镜头级视频版本记录，前端可手动指定剪辑版，也可按质量分自动择优；系统可导出只包含已完成视频 URL 的剪辑交付包 Markdown / JSON，也可导出失败/缺失镜头重试包、镜头多版本对比报告、素材引用完整性报告、剪辑台资产包、缩略图抽帧计划包和成片精修计划包；缩略图抽帧 worker 已可读取计划包执行或 dry-run 准备 ffmpeg 抽帧，并把缩略图状态回写 `seedance_production`；剪辑装配 worker 已可读取剪辑交付包生成 concat list，并支持 source copy 快速拼接或 H.264/AAC 转码装配，状态回写 `seedance_cut_assembly`；成片精修计划包已汇总装配输出、镜头时间轴、缩略图、SRT 字幕 cue、音频 cue、片头片尾卡和质检清单；系列工作台已支持查看版本对比面板，直接播放/打开视频版本并改选剪辑版，也支持导入素材库绑定 JSON。
- 连续性：连续性账本、上一集记忆、未回收线索、已回收线索、账本重建。
- 系列记忆引擎 V1-V12 基础版：在连续性账本中沉淀结构化叙事记忆，包括角色、关系、道具、地点、视觉资产、知识边界、关键事件、待核冲突和长期情景记忆；单集生成上下文会按当前集精准召回相关结构化记忆，并模糊召回已生成场景、对白、GEARS 分段和 Seedance 镜头片段，支持预览中筛选、锁定、排除和批量清理召回项，并按分集持久化到系列项目；已从 `scene_breakdown`、对白、知识包、GEARS 分段和 Seedance 镜头提示词包抽取成稿记忆；召回偏好支持 JSON 导入/导出；制作约束表已把系列规则、Seedance 镜头禁用元素、运镜连续性、资产约束和文化边界纳入账本、预览、生成提纲和 Bible 导出；记忆冲突报告已结构化检测角色状态、地点状态、关系状态、知识边界和制作约束冲突，并进入系列质量审计、预览和 Bible；预览区支持按类型、状态和实体关键词筛选后批量锁定、排除或清空偏好。
- 预览：单集生成前可预览完整上下文。
- 质量：单集质量、连续性审计、系列质量审计。
- 线索闭环：系列质量审计已批量检查长期线索的开启、推进、回收、超期、未绑定伏笔和重复伏笔，并给出建议修改集数。
- 知识观：知识库作为结构化决策系统，不作为资料仓库。
- 类型能力：15 个成片类型的样片化规则、全类型叙事流派库。
- 流派选择：普通故事生成页和 AI 漫剧系列页均可选择叙事流派强化。

## 高优先级缺口

### 1. 系列项目统一入口

当前 AI 漫剧系列项目仍是独立保存列表，和普通故事项目入口分离。

需要补：

- 将系列项目纳入统一项目首页。
- 区分故事项目、系列项目、已归档项目。
- 支持从统一项目入口继续规划、继续生成下一集、导出 Bible。

### 2. 流派机制质量评分升级

当前流派库已经进入提示词和修复建议，但质量评分仍偏轻量。

需要补：

- 针对每个流派定义专属检查器。
- 例如凡人流检查“低起点、资源逻辑、阶段突破、代价”；无限流检查“任务规则、失败代价、团队分工、结算钩子”。
- 在质量报告中显示“哪些流派信号已经满足、哪些偏弱”。

### 3. 单集蓝图可视化编辑

当前分集卡片支持编辑，但蓝图仍是文本字段。

需要补：

- 开场钩子、中段转折、结尾钩子、线索动作可视化成时间轴。
- 支持拖动或标记线索在哪集开启、升级、回收。
- 支持按角色查看每集状态变化。

### 4. 镜头级视频提示词交付

需要补：

- 已生成分集可汇总导出 Seedance 2.0 镜头提示词包。
- 已支持导出系列级生产状态的视频版本对比报告，并在系列工作台查看可播放的视频版本对比面板，列出当前剪辑版、自动推荐版本、质量分、失败原因和选择说明。
- 已支持导出素材引用完整性报告，按镜头列出人物/场景资产、`@图片` 槽位、缺槽位镜头和需上传素材项；已支持导入素材库绑定 JSON，将人物定妆图、场景图、道具图的实际 URL/文件 ID 稳定映射到素材项，报告可识别 `bound` / `missing_file` / `missing_reference_slot`。
- 已支持导出剪辑台资产包，把 ready 视频、选中版本、镜头顺序、素材槽位、已绑定素材文件和缺失素材项合并给剪辑/自动组装流水线。
- 已支持导出缩略图抽帧计划包，把 ready 视频、选中版本、抽帧秒、输出路径和 ffmpeg 命令提示输出给后续 worker。
- 已支持缩略图抽帧 worker：读取计划包，支持 dry-run / overwrite / 分集或镜头筛选 / 数量限制，真实执行时调用 ffmpeg 保存到系列项目目录，并把 planned / ready / failed / skipped 状态回写生产账本。
- 已支持剪辑装配 worker：读取剪辑交付包，支持 dry-run / overwrite / 分集装配 / 输出文件名，写出 ffmpeg concat 清单，真实执行时调用 ffmpeg 拼接到系列项目目录，并把 planned / ready / failed / skipped 状态回写 `seedance_cut_assembly`。
- 已支持基础转码策略：`assembly_mode=copy` 走快速无损 concat，`assembly_mode=transcode` 可输出 H.264/AAC MP4，并支持 1080p / 720p profile、fps、crf、preset。
- 已支持导出成片精修计划包：汇总装配成片路径、镜头时间轴、缩略图路径、SRT 字幕 cue、音乐/音效 cue、片头片尾卡和质检清单，供后续字幕烧录、混音或外部剪辑平台使用。
- 继续补外部剪辑平台对接，以及真实字幕/混音/片头片尾渲染 worker。

### 5. 系列记忆引擎升级

当前已完成 V1/V2/V3/V4/V5/V6/V7/V8/V9/V10/V11/V12 基础版：结构化记忆挂入连续性账本；生成单集后会从真实 `scene_breakdown`、对白、知识包、GEARS 分段和 Seedance 镜头提示词包中补充成稿记忆；生成下一集时会根据本集关键角色、知识焦点、主冲突、承接/伏笔/回收和相关集数进行精准召回；预览区可按类型、状态和实体关键词筛选召回记忆，锁定、排除、批量锁定、批量排除或批量清空偏好，偏好会按分集持久化到系列项目，并支持 JSON 导入/导出，后续预览/生成会默认应用；制作约束表会单独沉淀连续性、禁用元素、运镜、资产和文化边界约束，并进入预览、生成提纲和 Bible；记忆冲突报告已进入系列质量审计，按阻断/警告/观察分类提示修复；长期情景记忆索引 `episodic_memory` 已保存场景、对白、GEARS 和 Seedance 镜头片段，使用 `lexical-token-signature/v1` 做 embedding-ready 的模糊召回，并进入上下文预览、生成提纲和 Bible。

仍需要补：

- 后续在 30 集以上系列中接入真实 embedding 模型和外部向量库，用同一套 `episodic_memory` 数据结构替换当前词元签名检索。

## 中优先级缺口

### 6. 知识条目的 Agent 可读字段产品化

文档规范已经要求结构化字段，但录入和编辑界面还没完全产品化。

需要补：

- 条目编辑时支持 `knowledge_domain`、`entry_role`、`asset_usage`、`asset_split`。
- 支持关系字段：直接事件、相关地点、思想传播、后世纪念、创作母题。
- 搜索和匹配时优先使用结构字段，而不是只靠摘要。

### 7. 样片参考库可追溯

当前样片规则是结构化经验，缺少来源记录。

需要补：

- 为每个成片类型维护 5-10 个可追踪样片源。
- 样片只记录结构观察：开场、转折、镜头、文案、质量信号。
- 不保存受版权限制的原文内容。

### 8. 自动保存状态更明确

当前系列项目会自动保存，但用户感知还不够强。

需要补：

- 显示保存中、已保存、保存失败。
- 支持手动保存按钮。
- 分集卡片改动后明确提示“已影响第几集生成”。

### 9. 多版本对比

当前普通故事项目有版本思路，系列项目还缺少分集规划版本对比。

需要补：

- 系列规划版本快照。
- 对比分集卡片变更。
- 对比重建账本前后的线索状态。

## 低优先级但重要

### 10. 生成评测集

需要固定一批测试题材：

- 历史人物长篇。
- 神话传说长篇。
- 非遗工艺漫剧。
- 城市文旅漫剧。
- 儿童向传统故事。

每次改提示词、流派库、质量评分后，用固定题材做回归，观察结构完整度和类型质感。

### 11. 角色资产连续性

当前连续性偏剧情文本，角色视觉资产连续性还不够。

需要补：

- 角色服装、年龄、发型、随身道具、表情基调。
- 场景空间、固定陈设、色彩基调。
- 每集生成时自动带入资产稳定要求。

### 12. Bible 导出增强

当前 Bible 已包含大量结构，但可以更面向制作。

需要补：

- 角色表。
- 场景表。
- 线索表。
- 知识边界表。
- 流派机制表。
- 已生成集与待生成集状态表。

## 下一步建议

最值得继续做的顺序：

1. 流派机制质量评分升级。
2. 系列项目进入统一项目首页。
3. Seedance 外部剪辑平台对接和音频/字幕/片头片尾策略。
4. 长期情景记忆 V13：接入真实 embedding / 向量库，并做 30 集以上召回质量评估。
5. 知识条目的 Agent 可读字段产品化。
