使用边界：公开接口未提供字幕，AI 总结接口权限不足，本地也未配置转写 API key；所以下列内容不是逐字稿，而是基于可确认章节、视频标题简介、项目现有 AI 漫剧链路抽象出的可执行生产规则。

可吸收的方法：

- 提示词必须拆层：基础设定、氛围画质、画面内容。

- 爆款工作流不是只靠故事梗概，而是靠可复用的提示词分析、生成演示、功能讲解和分镜验证。

## 1. 非遗/工艺宣传片

目标：把非遗、传统工艺、民俗流程从资料介绍转成可拍的材料、工具、手部动作、流程、传承关系和当代困境。

补充模板：

- 主体：项目名称、类别、地域、来源等级。
- 材料：原料、颜色、质地、声音、气味、来源。
- 工具：工具名称、握持方式、运动方式、留下的痕迹。
- 流程：至少 3 个关键步骤，每步有动词和画面。
- 人物：传承人、学徒、匠人、合作社、展馆或家庭作坊关系。
- 视觉：微距手部、材料纹理、工具运动、成品前后对照。
- 当代：市场、学徒、材料、时间、审美、传播或保护困境。
- 边界：级别、传承人身份、获奖、年代、谱系必须核实。

## 2. 微纪录片

目标：把文化条目转成现场、史料、人物讲述、再现边界和当代回望组成的可信短纪录结构。

补充模板：

- 核心问题：观众带着什么问题进入？
- 现实入口：今天还能看到的地点、实物、声音、仪式或展陈。
- 来源提示：一手/权威来源、二手研究、地方口述分别是什么。
- 时间线：关键年代、地点、人物、事件节点。
- 讲述角色：馆员、研究者、传承人、当地居民、后人、主持人。
- 现场笔记：光线、声音、人流、路径、可拍节点。
- 再现边界：哪些只能做示意画面，不能写成真实影像。
- 结尾痕迹：今天还能回到哪个物件、空间或人群。

## 3. AI 漫剧

目标：把文化材料转成强钩子、角色稳定、对白冲突、表情动作、分镜提示和多镜头连续性的短剧生产包。

补充模板：

- 第一格钩子：异常画面、危险、误会、反转或强表情。
- 真实度：原创虚构、素材启发、传说改编、史实再现、机构审定。
- 主角目标：此刻想要什么。
- 对手压力：谁阻止、规则阻止、时间阻止还是环境阻止。
- 关系碰撞：一句对白让关系立刻撞起来。
- 场景锚点：一个空间和一个道具贯穿本集。
- 角色稳定：年龄、服饰、发式、随身物、表情关键词。
- 分镜层：基础设定、氛围画质、画面内容。
- 单镜头测试：验证角色、场景、画质、构图。
- 多分镜测试：验证连续动作、视线、道具位置和结尾钩子。

## 使用方式

录入素材时先判定目标成片类型，再按对应模板补字段。Story Agent 生成时会通过 `video_type` 自动读取当前类型的生产素材模板，并写入 prompt 与生成结果。当前 15/15 类型均已配置独立模板，不再以缺包方式绕过 readiness。

不要把这些样板条目直接当作事实写入 `data/provinces/*.md`；它们是补库清单和生产卡片。只有当来源、核实方法、待核点和资产拆分补齐后，才进入正式知识库。

优先补库顺序：

1. 先补 `ai_comic_drama`，因为现有项目生成记录最多，能最快进入单镜头/多分镜验证。
2. 再补 `heritage_promo`，因为当前库里非遗条目最多，但流程和资产拆分不足。
3. 再补 `documentary_short`，因为它对来源、现场、边界要求最高，适合建立可信度标杆。
