## 来源证据包模板

每张 P0/P1 卡都有一个来源证据包模板，统一包含：

- 来源目录
- 事实边界表
- 授权或同意
- 写回范围审查
- P0 题材额外包含专项安全检查

证据包不是来源本身，而是审稿工作台：它告诉人工审稿人要补哪些证据、哪些边界必须确认、哪些内容不能进入写回。

## 写回草案模板

每条候选写回队列都有一个 Markdown 草案模板，但全部仍是：

`template_pending_human_review`

允许进入模板的内容类型：

- 已审稿的生产素材摘要
- 已审稿的事实边界摘要
- 已审稿的禁用断言
- 已审稿的来源或授权缺口

禁止进入模板的内容：

- 生成故事正文
- 分镜
- GEARS segments
- Seedance prompt
- 对白
- 虚构剧情
- 医疗指导
- 敏感历史复现

## P0 专项检查样例

本轮新增 4 个 P0 检查样例：

- 创伤历史错误样例：血腥复现和虚构证词冒充
- 创伤历史可审样例：证据链和纪念空间表达
- 医疗伦理错误样例：药方比例、诊疗操作和疗效暗示
- 医疗伦理可审样例：文化记录、档案、标本和非医疗建议

这些样例不是观众稿，而是审稿检测样例，用来帮助后续测试和人工审稿统一口径。
