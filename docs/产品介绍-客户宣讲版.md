# 中华文化故事工坊 — 产品介绍

> 从文化知识到视频脚本，一站式AI驱动的内容创作平台

---

## 一、我们是谁

中华文化故事工坊是一款面向文化内容创作者的 **AI驱动全流程创作平台**。我们将中国传统文化知识库与AI故事生成引擎深度融合，帮助用户从一条知识条目出发，经过创意策划、剧本生成、质量审核，直达视频生产所需的分镜脚本——**一条链路，闭环完成**。

---

## 二、我们解决什么问题

### 🎯 知识到叙事的鸿沟

传统文化知识丰富，但大多以百科条目、学术论文的形式存在，**缺乏戏剧性叙事**。博物馆有展品说明，非遗有申报材料，地方志有记载——但没有人把这些变成能打动观众的故事。我们填补的就是这个"从知识到故事"的空白。

### 🎯 内容生产的专业性门槛

制作一条高质量文化视频，需要同时具备：
- 文化素养（不写错历史、不混淆传说与史实）
- 编剧能力（冲突、转折、人物弧光）
- 制作对接能力（分镜、时长、视觉提示）

多数创作者无法同时满足这三点。我们的平台 **内置文化约束引擎和专业叙事结构**，让不具备编剧背景的人也能产出专业级内容。

### 🎯 AI生成内容的文化可信度问题

市面上AI写作工具普遍存在的问题：把民间传说写成史实、混淆古今地名、对宗教/民族内容处理不当。我们的平台：
- **四级来源评级**（正史A级 → 民间口述D级）
- **可信度交叉认证**（至少两类不同来源互相佐证才标记"可靠"）
- **证据边界分离**（生成内容明确标注"史实/存疑/虚构创作"三段边界）

**确保AI生成的内容不会模糊历史与虚构的界限。**

### 🎯 创作流程碎片化

创作者在资料查阅、剧本撰写、质量审核、制作对接之间反复切换工具。我们的平台提供 **统一工作台**——从知识浏览到脚本导出，一站完成。

### ✍️ 故事创作工坊（StoryStudio）

三种创作模式，适配不同创作起点：

| 模式 | 适用场景 | 工作方式 |
|------|----------|----------|
| **条目模式** | 已有明确主题 | 输入关键词 → 自动匹配知识条目 → 单条目生成故事 |
| **主题模式** | 有方向但需知识支撑 | 输入创意主题 → 分析叙事需求 → 匹配知识包 → 生成 |
| **大纲模式** | 有完整构思需多源支持 | 输入故事大纲 → 提取知识需求 → 多条目组合 → 生成 |

**15种视频类型**：人物故事、历史戏剧、传说故事、AI漫画剧、儿童故事、文化宣传片、非遗宣传片、城市品牌片、社交短视频、纪录短片、科普视频、讲座视频、教育培训、场景短片、风景意境

**11种呈现风格**：电影感、纪录片、主持人叙事、旁白蒙太奇、竖屏短剧、AI漫画、2D动画、水墨风、儿童动画、博物馆展厅、社交媒体快切

**8种叙事结构**：单一事件戏剧、三幕戏剧、记忆拼图传记、见证证言、物件线索旅程、前后对比变革、案例重构、讲座论证

**21种叙事模式库**：凡人成长、使命传承、历史因果故事、权谋策略、英雄抉择、民间传说试炼、谜团揭示、群像交织、物件线索旅程、技艺修行、仪式流程、品牌符号、城市一日旅程、社交钩子对比、纪录片调查、知识缺口科普、讲座案例论证、训练循环、空间漫游、诗意风景、儿童寓言

### 🎬 AI漫画连续剧（长篇连载）

专为连续剧式内容打造的完整生产系统：

- **系列规划**：设定集数、时长、节奏模式、角色弧光、情节线程（铺垫/回收追踪）
- **单集蓝图**：每集独立生成，包含开场钩子、冲突、中段转折、结尾悬念
- **连续性账本**：自动追踪角色状态、开放线程、已回收线程、知识引用、每集记忆——**确保前后连贯，不穿线**
- **质量审核**：单集质量报告 + 全系列连续性审计 + 自动修复建议

### 🔧 故事质量与修复系统

| 检查维度 | 说明 |
|----------|------|
| 7点戏剧质量检查 | 中心事件、冲突、主角抉择、场景动作、高潮、结尾主题、非传记摘要 |
| 类型专属质量检查 | 每种视频类型有独立的必要元素、弱节拍检测、禁用模式检测 |
| 自动修复 | 质量不合格时自动识别修复动作，重新生成问题段落 |
| 证据边界标注 | 史实/存疑/虚构创作三段边界明确标注 |

### 🎨 创意参考与风格包

- 收藏喜欢的故事文本/视频作为 **创意参考**
- 系统自动分析参考的叙事手法、开头钩子、冲突模式、情感曲线等 **10+维度**
- 多个参考蒸馏为 **风格包**，形成可复用的创作规则集
- 生成时可引用风格包，调节参考强度（轻/中/强）和类型严格度（宽松/平衡/严格）

**不是"模仿文本"，而是"提取创作方法论"。**

### 📡 GEARS视频生产对接

三种对接模式，适配不同深度：

| 模式 | 说明 |
|------|------|
| API拉取 | grears v2主动调用API获取分镜数据 |
| Webhook推送 | 故事生成完成后自动通知grears v2 |
| 全流程联动 | 草稿→制作→视频→发布 全生命周期自动流转 |

GEARS交付包包含：角色资产（外貌/服饰/道具）、场景资产（类型/环境/氛围）、分镜交付单元（台词/角色/时长/画格数/节拍数）、Markdown导出、校验备注。

### 🤖 MCP智能工具链（14项）

全部知识库操作可通过AI助手（如Claude Code）直接调用：

- 知识搜索、语义匹配、条目详情查询
- 三轴补充（版本差异、同地同类、关联网络）
- 来源可信度核查（外部权威+内部互证）
- 网页文章抓取、B站视频一键录入
- 脚本骨架生成、故事文本生成

**让AI助手成为知识库的智能操作员。**

## 四、我们的独特优势

### 1️⃣ 知识即决策系统

知识库不是文件仓库，而是 **Agent可消费的决策系统**。每条条目声明自身角色、使用约束、可信边界、关联关系——让AI不只是检索文本，而是做出智能创作决策。

### 2️⃣ 冲突评分戏剧引擎

我们不做百科摘要式生成。引擎从条目中提取戏剧性事件，用关键词评分算法（冲突/抉择/逆转/权谋/牺牲加分，传记摘要扣分）选出最具张力的事件，生成有主角抉择、反转和高潮的 **真正戏剧叙事**。

### 3️⃣ 证据边界三段分离

生成内容明确标注三段边界：✅史实（有交叉佐证）、⚠️存疑（缺乏佐证）、🎨虚构创作（戏剧化处理）。**杜绝AI生成内容模糊历史与虚构。**

### 4️⃣ 21模式叙事模式库

业内最系统的叙事模式分类，每种模式定义主角引擎、冲突引擎、节奏模式、场景配方、质量信号和反模式。不是"写一个故事"，而是"按专业叙事方法论写一个故事"。

### 5️⃣ 连续剧连续性引擎

从单集故事到多集连续剧的完整质量保障：连续性账本自动追踪角色状态和情节线程，跨集质量审计确保不穿线。**目前市面上唯一具备长篇连续剧连续性管理能力的文化内容平台。**
