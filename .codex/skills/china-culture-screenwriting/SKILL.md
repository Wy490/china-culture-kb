# China Culture Screenwriting

Use this skill when the task is about story quality, not only code shape. It adapts general Chinese screenwriting practice to this repository's cultural knowledge boundaries.

## Workflow

1. Identify the source:
   - knowledge-base entry
   - user outline
   - existing generated story
   - novel/story adaptation
   - series episode context
2. Separate source status before writing:
   - verified knowledge-base facts
   - plausible dramatization
   - explicit fictional additions
   - unknown or forbidden claims
3. Choose the output form:
   - full story text
   - scene breakdown
   - short drama episode
   - AI comic-drama episode
   - documentary/explainer/promo script
   - revision notes or repair plan
4. Write scenes as visible action. Each scene needs place, action, conflict/discovery, emotional turn, and a reason it belongs.
5. Preserve cultural and factual boundaries. Never convert a knowledge note into a false biography, false location claim, or invented tradition without marking it as fiction.

## Required Habits

- Prefer concrete action over praise and summary.
- Give characters goals, pressure, choices, and consequences.
- For historical or cultural material, keep a visible line between evidence and invention.
- For AI comic-drama, strengthen hook, expression, dialogue conflict, panelable action, and episode-ending question.
- For heritage/culture promotion, show process, hands, places, tools, inherited dilemma, and contemporary relevance.
